MODULE 32 Examination 32: To Study the Effect of a Test Drug on Spatial Learning and Memory in the Barnes Maze in Scopolamine-Treated Mice
EXPERIMENT OBJECTIVE

Barnes Maze: Spatial Learning and Memory

A mouse on a bright, open circular table wants to escape into a dark hole. Twenty holes lie round the rim, but only one leads to an escape box. Using cues around the room, the mouse learns where the box is. Primary latency and primary errors fall as it learns. With the box removed in the probe trial, the time near the old hole shows its memory.

You do every step yourself: set up the table (light, escape box, cues), habituate the mice, give the injections, run the trials, clean and rotate the table between hand-run trials and read the tracker. Daily sessions can be finished by the tracker once you have run a trial by hand, but the probe trials are yours.

1

Principle

Described by Carol Barnes (1979), the task uses a rodent's natural preference for dark, enclosed places. Bright light is the mild motivator. It involves no swimming and no food restriction, so it is less stressful than the water maze and suits mice well.

2

Measures

Primary latency: time to first reach the target hole. Primary errors: pokes into wrong holes before that. Strategy: random, serial (hole after hole) or spatial (straight to the target).

Probe: time in the target quadrant (chance is 25%, or 22.5 s of 90) and pokes at the target hole.

3

Design and statistics

I: saline + saline. II: saline + scopolamine. III: test drug + scopolamine. Use two-way repeated-measures ANOVA for primary latency across days, and one-way ANOVA with Dunnett's test against Group II for the probe.

Requirements

  • Swiss albino mice 20–30 g, 6 per group (18 in all)
  • Scopolamine HBr 1 mg/kg i.p., normal saline
  • Test drugs: donepezil 1 mg/kg, rivastigmine 1 mg/kg, piracetam 200 mg/kg, caffeine 20 mg/kg, diazepam 2 mg/kg (all i.p., 10 mL/kg)
  • Barnes table with 20 holes, escape box, start chamber, overhead lamp, wall cues, video tracker, 70% ethanol

Procedure

  1. Mark, weigh and randomise. Prepare the solutions and give the injections at −60 min and −30 min. The same doses are repeated each day.
  2. Set the lamp to 1000 lux, fit the escape box and hang the cues. Habituate each mouse to the box.
  3. Place the mouse in the start chamber in the centre for 10 s, lift the chamber and start the timer. Allow 180 s.
  4. Between trials, rotate the table and clean it with 70% ethanol. The box stays at the same place in the room, so odours on the table give no clue.
  5. On Day 5 remove the box and allow 90 s.
  6. Read the tracker and analyse.
